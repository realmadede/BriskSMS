Zero-Guesswork Reconciliation Protocol & Candidate Matching
Deterministic rules governing financial settlement, candidate ranking, and auditor audit trails
1. Deterministic Rule Matching
Automated invoice settlement requires an exact match on provider transaction reference and amount. If an end-user inputs an altered reference or makes a partial payment, the system routes the payment to this Review Queue instead of guessing settlement.
2. Candidate Match Suggestions
When inspecting a disputed payment, the engine queries GET /v1/reconciliation/payments/:id/candidates, scoring unpaid invoices by customer phone number, name match, and creation time windows to help accountants verify the intended order.
3. Immutable Ledger Audit Trail
Every manual action (manual allocation, partial credit, or refund flag) is signed with the acting staff user ID and stored in an append-only audit log. Raw provider evidence is never modified or deleted.

Companion Gateway Deployment & Cellular SLA Guidelines
Production operational standards for sub-15s payment detection and zero gateway downtime
1. Cellular Signal Strength (> -95 dBm)
Position companion phones in open office areas or near exterior windows. Cellular signal weaker than -95 dBm (CSQ < 14) causes carrier SMS delivery queues to spike up to 45s+ and induces missed telco broadcasts.
2. Dedicated Continuous AC Power
Connect relay phones to a dedicated AC charging block. Ensure Android OS Battery Optimization is exempt (REQUEST_IGNORE_BATTERY_OPTIMIZATIONS) so the background ingestion daemon is never killed by OEM power governors.
3. Active-Active Hardware Redundancy
For business-critical checkout points, pair ≥ 2 Android phones in an active-active pool. If Device A experiences battery depletion or OS reboot, Device B automatically processes all incoming provider notifications without merchant interruption.
4. Dual-SIM Carrier Limit Auto-Failover
Equip phones with dual SIMs (e.g. SIM 1 Vodacom, SIM 2 Airtel). When a SIM card reaches the carrier daily limit (400 SMS/day), the BriskSMS background dispatcher transparently switches outbound messaging to the secondary SIM slot.
